# Synchronisierung der Benutzer

Diese Weboberfläche dient zur Live-Synchronisierung der Benutzer für die Hausmeistersteuerung. Durch die Oberfläche können mithilfe eines Stundenplans, Benutzer (Schüler) ihren Zeitslots zugewiesen werden. So muss sich niemand direkt mit den Authentik-Gruppen auseinadersetzen.
